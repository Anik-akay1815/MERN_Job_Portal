# MERN Job Portal

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Tailwind CSS

## Features
- User & Company Authentication
- Role Based Authorization
- Job Posting
- Apply for Jobs
- Company Dashboard
- Applicant Management
- Accept/Reject Applications
- User Profile
- Company Profile
- Edit Profile
- Protected Routes

## Upcoming Features
- Resume Upload
- Search & Filter
- Saved Jobs
